# Governed Project source reconciliation

This optional read-only slice connects original public HC wage Project allocations to PB service revenue over the **same complete approved time documents**. It uses existing source owners, GL, identity and AR. It creates no ledger, migration, source mutation, financial effect or cash allocation.

Select one qualified workspace/organization/entity, native Project, period, posted payrun and posted invoice. Current `people_project_payroll.read`, `project_time_billing.read`, `finance_core.read` and `receivables.read` are all required. Each original wage, payment, invoice, collection and hourly customer price is admitted using its captured amount policy. The ordinary nonowner, nonbypass connection is required; membership of the private personnel runtime group is refused. No employee, private rates, wage allocation per employee, employment or private HC command table is queried.

The existing owners perform current persisted hierarchy/permission admission. A fixed SELECT captures the public source, claims, original prices, native headers, lines, dimensions, effects, acknowledged post commands, source audit/outbox records, accounts and native AR allocations in one PostgreSQL statement snapshot. Captured source amounts are admitted again before returning. The snapshot timestamp describes that capture; later cash operations are absent from that snapshot rather than inconsistently appended to only one population.

Each source's native header remains `Validated`; its immutable posting effect and source phase establish publication. Reconstruct the original review snapshot from native rows, check its seal and the native ACK result/request, bind three distinct financial humans, and match exact debit/credit account roles and Project attachments. Approved-price seal/approver/policy/effective dates bind the original applied service rates. Whole-time wage and billing claim histories are separate: both must end consumed by these exact sources with no duplicate or detached interval. Unknown posted Expense/Income rows for the selected Project/period refuse the selected-source interpretation.
