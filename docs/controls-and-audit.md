# Controls and Audit

ReconForge ERP is built for practical operational controls rather than abstract data matching.

## Finance Controls

- GL spare-parts expense should agree with issued inventory value.
- Manual journals should be traceable to source documents and work orders.
- Variances should be reviewed before period close.
- WIP should be reviewed for aging, collectability, and closure action.

## Stores Controls

- Parts should be received before issue.
- Direct purchase-and-fit should be exceptional and documented.
- Cancelled purchase orders should not support stock or cost postings.
- Old parts should be returned when policy requires cores or replaced items.

## Workshop Controls

- Work orders should link parts, labor, customer, equipment, invoice, and GL impact.
- Closed work orders should not receive late stock issues.
- Work orders with cost should be invoiced or carried in WIP with explanation.
- Long-open work orders should be assigned to owners and reviewed.

## Auditor Workflow

Auditors can use the management pack to:

- Select high-risk exceptions by score and value.
- Trace matched records from stock source document to GL reference.
- Review unmatched stock movements and unmatched GL line items.
- Test WIP aging and old-part return controls.
- Document management responses and remediation actions.

ReconForge does not assert that an exception is fraud or misstatement. It identifies records where the control evidence is incomplete, inconsistent, or outside configured tolerance.
