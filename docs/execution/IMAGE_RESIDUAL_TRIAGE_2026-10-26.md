# F3 residual image vulnerability triage — read-only

Scope: output/enterprise-program-20261026/image-f3cfbad9.grype.json, Python3.12.15 on Alpine3.24 and BusyBox1.37.0-r31. Original unchanged policy passed with0Critical/High,9Medium package matches and1Negligible match. The BusyBox CVE occurs in busybox, busybox-binsh and ssl_client; these are three package matches of one vulnerability, not three independent defects. Findings remain present. No code, runtime, scanner database, policy, VEX or suppression was changed by this review.

## Supported fix and distribution blocker

[Official Python3.12.16 release](https://www.python.org/downloads/release/python-31216/) dated2026-10-25 explicitly includes gh157579, the TemporaryDirectory cleanup race assigned CVE-2026-12345. This is a supported3.12 security patch, not justification to jump to unsupported3.13/3.15 merely because Grype suggests those branches. Official release notes also identify other security content; this triage does not claim a single upgrade clears every reported match.

However the exact selected official image python:3.12.16-alpine3.24 is not available: lead's docker buildx imagetools inspect --raw returned `not found`, not a timeout. Raw python-31216-image-query.log is retained. Therefore remediation is BLOCKED on distribution availability plus normal image qualification. No invented tag/digest, custom runtime build, unsupported minor/OS jump, release exception or current-artifact fix is claimed. Any future candidate must be digest-pinned, rebuilt and scanned/tested as its own artifact.

## Evidence and limits

Authenticated gh api fetched official python/cpython PR metadata and every CPython commit linked by the actual Grype matches. Raw files engineering-image-cpython-pr-*.json, engineering-image-cpython-commit-*.json and engineering-image-cpython-commits-index.json preserve titles, branch-labelled backports, file patches and the important reverts. No GitHub references were followed via unauthenticated fetch.

Source search covered reconforge for b64decode/altchars, imaplib/poplib/js_output/pkgutil.get_data, TemporaryDirectory/rmtree, wget/busybox and subprocess callsites. Direct source reachability is not a dependency-wide dynamic reachability proof. No exploit was executed, no production data accessed and no image/runtime package was changed. BusyBox source distribution lookup and optional Python source archive corroboration are not required evidence for conclusions above and are not treated as completed qualification.

Disposition: keep9Medium+1Negligible package matches visible with zero new exceptions. Prioritize a supported3.12.16 image once the selected official distribution exists and can pass exact-artifact gates; separately resolve remaining findings through reviewed application mitigations/upstream-supported fixes and authenticated distro provenance. Policy pass is not zero vulnerabilities, and this report does not waive release acceptance gates.

### Additional primary-source corroboration completed

Official Python3.12.16 source archive was downloaded read-only from https://www.python.org/ftp/python/3.12.16/Python-3.12.16.tar.xz (20,839,652bytes) and verified against the official release-page SHA256 b5796915dc45ff745cfb4e990a7e7c93d6f546328a102ce31448d69ebc37575c. Selected stdlib files were read without installing/executing that runtime. The tempfile source contains descriptor-relative cleanup/perms handling consistent with the announced race fix. The3.12.16 POP3 command source still sends line+CRLF without the reviewed new control rejection; IMAP still constructs command data from arguments; cookies.js_output still inserts escaped cookie text into script. Thus3.12.16 must not be claimed to clear every scan finding.

[Official Alpine3.24-stable BusyBox APKBUILD](https://git.alpinelinux.org/aports/plain/main/busybox/APKBUILD?h=3.24-stable) was also retrieved as engineering-image-busybox-APKBUILD.txt: pkgver1.37.0/pkgrel31 agrees with the report, while its secfixes block does not name60876. This source metadata corroborates the distro context but does not replace an installed APK payload/patch verification. All unresolved dispositions above remain unchanged. These are source corroboration artifacts, not a compiled runtime, available Docker tag, remediation or exemption.
