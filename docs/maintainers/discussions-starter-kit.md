# GitHub Discussions Starter Kit

Use these drafts to open practical, moderated discussions without implying customer adoption or production proof.

## Welcome To ReconForge ERP

**Opening post**

Welcome to ReconForge ERP, a local-first, export-based open-source toolkit for ERP reconciliation, stock-to-GL matching, WIP/work-order controls, rule packs, evidence binders, and client handoff outputs.

This project is early-stage. We are looking for feedback from accountants, controllers, auditors, ERP consultants, inventory/stores teams, and workshop/fleet operators who can review the workflow from synthetic or anonymized exports.

**Questions**

- What role or workflow brought you here?
- Which ERP export problem would you most like to make repeatable?
- Which docs or demo steps were unclear?

**Moderation note**

Please do not post live ERP data, customer names, employee details, invoice values, GL accounts, credentials, or private financial information.

## Pilot Feedback And Use Cases

**Opening post**

We are looking for conservative pilot feedback using synthetic or anonymized exports. The goal is to identify practical gaps in setup, reconciliation, reporting, review workflow, evidence binder, and client handoff steps.

**Questions**

- Which workflow did you try?
- What blocked setup or review?
- Which output would a finance or audit reviewer trust or question?

**Moderation note**

## Rule Pack Ideas

**Opening post**

Rule packs encode explainable controls for ERP, inventory, WIP, purchasing, workshop, and audit workflows. We are collecting practical rule ideas that can be tested with synthetic data.

**Questions**

- What control objective should the rule address?
- What source files and fields are needed?
- What exception should be produced when the rule fails?

**Moderation note**

Describe business risks in plain English before suggesting YAML.

## Auditor And Accountant Feedback

**Opening post**

ReconForge aims to produce local reports and evidence packs that are understandable to finance and audit users. We would like feedback on terminology, exception summaries, evidence structure, and review workflow.

**Questions**

## Workshop And Fleet Control Gaps

**Opening post**

ReconForge includes workshop, spare-parts, fleet, work-order, WIP, purchase, and old-part return scenarios. We are collecting feedback from teams that manage repairs, stores, service operations, and fleet maintenance.

**Questions**

- Which exports do stores or workshop managers actually have?

**Moderation note**

## Security And Local-First Workflows

**Opening post**

ReconForge is local-first because ERP exports can be sensitive. We are looking for feedback on safe file handling, redaction, evidence sharing, generated HTML, and local workflow expectations.

**Questions**

- Which sharing risks worry you most?
- Are the redaction and client pack docs clear enough?
- What security checks would increase confidence?

**Moderation note**

Report suspected vulnerabilities through the private process in `SECURITY.md`, not public discussion threads.
