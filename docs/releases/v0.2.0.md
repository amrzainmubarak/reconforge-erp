# ReconForge ERP v0.2.0 Release Notes

ReconForge ERP v0.2.0 expands the project from a reconciliation prototype into a broader local-first ERP audit intelligence platform.

## Added

- YAML rule engine with composable operators and CLI commands for validation, listing, and execution.
- Control packs for audit basics, Odoo inventory valuation, SAP MB51/FAGLL03, workshop spare parts, fleet maintenance, manufacturing WIP, and dealership service.
- Audit evidence binder for High and Critical exceptions.
- Data anonymizer that preserves referential integrity across ERP exports.
- Synthetic data generator for workshop, manufacturing, and fleet scenarios.
- Benchmark engine with Pandas support and optional DuckDB engine handling.
- ReconForge Studio, a local FastAPI web interface for reviewing outputs.
- Product strategy, market research, architecture, plain-English, Arabic, playbook, benchmark, launch, application, and commercial strategy documentation.
- Security workflows, Dependabot, CodeQL configuration, and pre-commit hooks.

## Improved

- Management pack generation now also writes `summary.md`.
- Docker context includes control packs and documentation.
- Makefile demo covers rule packs, evidence binder, anonymization, synthetic data, and benchmarking.
- README positioning now emphasizes ReconForge ERP as the open-source audit layer between inventory operations and financial accounting.

## Compatibility

The v0.1 CLI workflow remains supported. New features are additive.

## Known Limits

- Native ERP connectors are planned; v0.2 remains export-driven.
- Studio is intentionally lightweight and reads generated local files.
- DuckDB is optional and requires installing `reconforge-erp[duckdb]`.
