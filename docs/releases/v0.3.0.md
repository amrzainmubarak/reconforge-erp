# ReconForge ERP v0.3.0 Release Notes

## Release Summary

ReconForge ERP v0.3.0 strengthens the project as a local-first ERP reconciliation and audit intelligence platform. It is not labeled v1.0.0 because native connectors, workflow review states, and enterprise deployment hardening remain roadmap items.

## Major Features

- Expanded advanced rule engine with duplicate, cross-file, variance, date, and aging operators.
- Rule explanation CLI.
- Fifteen control packs with risk models and sample commands.
- Risk intelligence package.
- Evidence binder review forms, HTML index, and Excel evidence register.
- Anonymization profiles and amount noise.
- Synthetic data support for workshop, manufacturing, fleet, dealership, and service industries.
- Benchmark HTML report and engine registry.
- Matching strategies with confidence, similarity, and review-required metadata.
- Offline exception explanation layer.
- Plugin/connector foundation.
- Expanded Studio pages.
- Market intelligence, category strategy, risk, anonymization, synthetic data, AI, plugin, privacy, and security model docs.

## Breaking Changes

No intentional breaking CLI changes. Existing v0.1/v0.2 commands remain supported.

## Migration Notes

Existing users can continue running standard reconciliation commands. New users should review control packs and choose the packs relevant to their ERP workflow.

## Demo Commands

```bash
reconforge validate examples/sample_data
reconforge reconcile stock-gl --input examples/sample_data --config config/reconforge.yml --output output
reconforge rules run --input examples/sample_data --pack control-packs/audit-basic --output output/rules
reconforge report management-pack --input examples/sample_data --config config/reconforge.yml --output output
reconforge report evidence-binder --input output --output output/evidence
```

## Known Limitations

- Native ERP connectors are foundations only.
- Studio remains local and lightweight.
- DuckDB is optional.
- AI assistance is offline deterministic unless future providers are explicitly added.

## Next Roadmap

- Odoo/SAP mapping profiles.
- Exception review state workflow.
- Multi-period comparison.
- Self-hosted Pro review workflow experiments.
