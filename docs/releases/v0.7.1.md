# ReconForge ERP v0.7.1

ReconForge ERP v0.7.1 is an evidence-bounded, foundation-stage candidate for local-first, export-based pilot evaluation. It consolidates the Phase 0 financial-correctness, deterministic-replay, hostile-input, authorization, dependency, and reproducibility work while preserving conservative product claims.

This candidate strengthens self-hosted/local-capable foundations. It is not a hosted production service, enterprise-ready claim, direct connector suite, compliance certification, audit opinion, legal signature system, or replacement for ERP, GRC, audit, or close platforms.

## Highlights

- Strict exact financial input defaults with explicit versioned legacy replay only.
- Deterministic Pandas/DuckDB reconciliation digests over the declared Python 3.11/3.12 lower/current engine matrix.
- Bounded structured, tabular, persisted-JSON, backup, export, and hostile-file ingress contracts.
- Deny-by-default scope checks and creator/reviewer segregation-of-duties properties.
- Live hosted PostgreSQL/Redis boundary verification and checksum-pinned Docker build/runtime parity.
- Universal Python lock and an npm lock with HTTPS resolution and SRI for all registry entries.
- Tag-only, non-publishing provenance and per-artifact CycloneDX SBOM candidate workflow, still pending a GitHub-verified signed tag on merged `main`.
- Synthetic enterprise demo evidence only; do not use live customer data.

## Verification boundary

Identified pull-request runs pass Python 3.11/3.12, Ruff, Mypy, pytest, package build, four no-skip engine cells, live server boundaries, Docker build/runtime parity, Bandit, locked dependency audits, Gitleaks history/tree scans, npm audit, and CodeQL. Exact run identities and limitations are retained in `docs/execution/EVIDENCE.md`.

The signed release candidate workflow has not yet run for v0.7.1. Until its retained provenance and SBOM bundles independently verify, do not claim signed release integrity, SLSA level, artifact provenance, immutable publication, compliance, certification, or production readiness.
