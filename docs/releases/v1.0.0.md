# ReconForge ERP v1.0.0 Readiness Note

ReconForge ERP is not yet recommended for a v1.0.0 label.

## Honest Recommendation

Use v0.3.0 for the current release. The project is credible and useful, but v1.0.0 should wait until native connector foundations, review workflow, package installation, documentation, and enterprise hardening have more production mileage.

## What v1.0.0 Should Include

- Stable connector SDK.
- Odoo/SAP export mapping profiles.
- Exception review lifecycle.
- Documented upgrade policy.
- More benchmark coverage.
- More user feedback from real anonymized workflows.
