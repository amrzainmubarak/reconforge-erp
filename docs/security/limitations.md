# Security And Product Limitations

Implemented:

- Local-first finance controls foundations for exported ERP data.
- DB-backed workflow, identity, RBAC, audit, backup, and restore foundations.

Partially implemented:

- Enterprise workflow breadth is growing, but not complete.
- Studio DB pages are intentionally lightweight and server-rendered.

Roadmap:

- SSO/SCIM design.
- More deployment and observability hardening.
- More API and Studio coverage for all DB-backed workflows.

Not supported:

- Enterprise-ready claim.
- SOC 2, ISO, SOX, Big 4 approval, audit opinion, legal certification, digital signature, or non-repudiation claim.
- Direct ERP connectors.
- SaaS/cloud behavior or telemetry.
