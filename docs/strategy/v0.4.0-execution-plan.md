# v0.4.0 Execution Plan

## Objective

Make ReconForge ERP credible for export-based Odoo and SAP users by documenting the rule-pack schema, strengthening mapping profiles, and adding tests that enforce profile structure.

## Priority Order

1. Rule-pack schema reference.
2. Odoo stock valuation mapping profile.
3. SAP MB51/FAGLL03 mapping profile.
4. Better demo commands.
5. Better sample mapping docs.
6. Labels and issue structure improvements where possible.

## Workstream A - Rule-Pack Schema Reference

Create `docs/rule-pack-schema-reference.md`.

Required content:

- `pack.yml` schema.
- `rules.yml` schema.
- `mapping.yml` schema.
- `risk_model.yml` schema.
- Valid examples.
- Invalid examples.
- Supported operators.
- Severity model.
- Confidence model.
- Risk impact model.
- Evidence fields.
- Contributor checklist.
- Validation command examples.

Acceptance criteria:

- The doc exists and includes examples for all core YAML files.
- Supported operators match `reconforge.rules.operators.SUPPORTED_OPERATORS`.
- The doc distinguishes implemented validation from documented mapping-profile conventions.

## Workstream B - Odoo Mapping Profile

Improve `control-packs/odoo-inventory-valuation/`.

Required files:

- `README.md`.
- `mapping.yml`.
- `rules.yml`.
- `expected-exceptions.md`.
- `sample-command.md`.

Required coverage:

- Stock moves.
- Stock valuation layers.
- Account move lines.
- Product master.
- Accounts.
- Work orders if available.
- Invoices if available.

Guardrail:

- Do not claim direct Odoo API support. This is an export-based workflow.

Acceptance criteria:

- Mapping profile identifies Odoo source models and canonical ReconForge datasets.
- Rules validate with `reconforge rules validate`.
- README gives a practical sequence from export to mapped CSVs to rules.

## Workstream C - SAP Mapping Profile

Improve `control-packs/sap-mb51-fagll03/`.

Required files:

- `README.md`.
- `mapping.yml`.
- `rules.yml`.
- `expected-exceptions.md`.

- Posting date.
- Document number.
- Reference.
- Amount.

Guardrail:

- Do not claim direct SAP connector support. This is an export-based workflow.

Acceptance criteria:

- Mapping profile identifies SAP export fields and canonical ReconForge datasets.
- Rules validate with `reconforge rules validate`.
- README explains how to handle layout differences without implying live SAP connectivity.

## Workstream D - Tests

Add tests for:

- Rule-pack schema docs presence.
- Odoo mapping pack structure.
- SAP mapping pack structure.
- `mapping.yml` required keys.
- `rules.yml` valid YAML.
- Sample-command files present.
- Expected-exceptions files present.

Acceptance criteria:

- Tests fail if the Odoo or SAP pack loses required files or mapping keys.
- Tests fail if rules YAML is invalid or the packs cannot be loaded.

## Release Gate

v0.4.0 should not be presented as direct Odoo/SAP connector support. The correct claim is:

ReconForge ERP includes export-based Odoo inventory valuation and SAP MB51/FAGLL03 mapping profiles, deterministic rule packs, and local evidence/report workflows.
