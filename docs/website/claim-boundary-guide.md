# Claim Boundary Guide

Use this guide when writing website, launch, README, release, social, or buyer-facing copy for ReconForge ERP.

## Default Positioning

ReconForge ERP is a local-first, export-based finance controls and reconciliation platform foundation. It helps users inspect local ERP exports, run transparent checks, prepare local evidence outputs, and evaluate workflow foundations with synthetic or approved local data.

## Allowed Wording

- local-first
- export-based
- self-hosted/local-capable foundations
- pilot-ready open-source toolkit for local evaluation
- finance controls platform foundations
- synthetic enterprise demo
- local evidence preparation
- checksum integrity aids
- review workflow metadata
- DB-backed foundations
- early-stage
- foundation-stage
- generated from local CSV/XLSX exports
- no cloud upload required for core workflows

## Use With Care

Use these only with context:

- "audit" as in "audit preparation", "audit evidence preparation", or "internal audit review support"
- "certification metadata" only as workflow metadata, not compliance certification
- "API" only as local REST API foundation, not public SaaS platform
- "Studio" only as local Studio foundation, not managed hosted workspace
- "Docker" only as build/runtime status that was actually verified

## Forbidden Wording

Do not use:

- enterprise-ready
- SOX compliant
- SOC 2 certified
- ISO certified
- Big 4 approved
- BlackLine replacement
- FloQast replacement
- Workiva replacement
- audit opinion
- legal signature
- non-repudiation
- guaranteed compliance
- production SaaS
- direct ERP connector suite
- real customer traction
- proven ROI
- customer logos
- testimonials
- revenue traction
- guaranteed savings
- vendor replacement

## Safer Alternatives

| Avoid | Prefer |
| --- | --- |
| enterprise-ready | pilot-ready for local evaluation |
| SOX compliant | supports local control review workflows |
| SOC 2 certified | includes security documentation and local security checks |
| direct ERP connector suite | export-based ERP profiles |
| audit opinion | local evidence preparation |
| legal signature | checksum integrity aid |
| proven ROI | no ROI claim |
| replacement for enterprise tools | lightweight local complement for export-based review |

## Demo Boundaries

- The standard demo uses repository sample data.
- The synthetic enterprise demo uses generated synthetic data.
- Public screenshots should come only from repository sample outputs or regenerated synthetic outputs.
- Do not present demo outputs as customer environments, customer results, ROI proof, compliance proof, or production deployment evidence.

## Release Copy Checklist

Before publishing:

- Confirm all claims match implemented behavior.
- Confirm local-first/export-based language is present.
- Confirm no SaaS, direct connector, certification, audit opinion, legal signature, customer traction, or ROI claim slipped in.
- Confirm support and package terms are draft/non-contractual where relevant.
- Confirm any screenshots are generated from sample or synthetic data.
- Confirm release status and version are accurate.
