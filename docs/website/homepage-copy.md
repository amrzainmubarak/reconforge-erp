# Website Homepage Copy

Draft website copy for ReconForge ERP. This copy should be treated as conservative launch material for the current foundation stage, not as a production-readiness, customer-traction, compliance, or audit-assurance claim.

## Hero

Headline:

ReconForge ERP turns local ERP exports into reviewable reconciliation, controls, evidence, and close-workflow outputs.

Subheadline:

A local-first, export-based finance controls platform foundation for teams that need transparent stock-to-GL checks, WIP/work-order review, rule-pack controls, evidence preparation, and pilot-ready demo workflows without uploading ERP data to a hosted service.

Primary call to action:

Run the local demo

Secondary call to action:

Read the buyer FAQ

Boundary line:

ReconForge is an early-stage open-source toolkit for local evaluation. It does not provide SaaS hosting, direct ERP connectors, audit opinions, compliance certification, legal signatures, customer adoption proof, or ROI claims.

## Who It Is For

- Finance controllers reviewing exported ERP balances, stock movements, GL rows, WIP, and close tasks.
- Internal audit teams preparing local evidence folders and exception registers.
- ERP consultants testing export-based mappings and control packs.
- Open-source maintainers and technical evaluators reviewing finance controls foundations.
- Pilot teams that need synthetic, anonymized, or approved local data workflows.

## What It Does

- Reads local CSV/XLSX exports.
- Runs stock-to-GL, work-order, WIP, variance, rule-pack, mapping, and review workflows.
- Generates local reports, Excel workbooks, Markdown summaries, HTML dashboards, review registers, evidence folders, and client handoff packs.
- Provides foundation-stage local SQLite services for accounts, close tasks, evidence registry, journal controls, intercompany, control testing, matching, unified exceptions, metrics, API routes, and Studio DB pages.
- Creates a synthetic enterprise demo package so evaluators can inspect platform foundations without live customer data.

## Local-First Positioning

ReconForge starts from files users already control: CSV and XLSX exports from ERP and operational systems. Core workflows run locally and write outputs to local folders. The project does not require a ReconForge account, paid API, hosted storage, telemetry, or cloud upload for core workflows.

## Proof Without Overclaiming

Use generated sample outputs, the 10-minute demo, and the synthetic enterprise demo for public walkthroughs. Do not add fake logos, testimonials, customer names, revenue, adoption metrics, ROI figures, or unsupported compliance language.

## Footer Boundary Copy

ReconForge ERP is local-first and export-based. It supports local evidence preparation and finance controls review workflows, but it does not issue audit opinions, certify compliance, provide legal signatures, replace ERP or enterprise close platforms, or claim direct ERP connector support.
