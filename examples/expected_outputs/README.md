# Expected Output Signals

The sample data is designed to produce matched stock/GL pairs, stock movements without GL, GL entries without stock, a material value difference, reference mismatches, missing old-part returns, direct purchase-and-fit risk, cancelled PO linkage, and WIP aging over 90 days.

Exact row counts can change as matching tolerances are adjusted in `config/reconforge.yml`, but the default configuration should surface each control category.
